An AI agent is a software system that uses an AI model (usually an LLM) to pursue a goal autonomously. Instead of just answering one prompt, it:

1. **Perceives**: takes in input, such as a user request, files, or tool results.
2. **Plans**: decides which steps are needed.
3. **Acts**: calls tools (run commands, search, edit files, call APIs).
4. **Observes and iterates**: checks the results, adjusts, and repeats until the goal is met.

The key difference from a plain chatbot is the loop of reasoning, tool use, and feedback. It can take multiple actions on its own. I'm an example: I read code, run tests, and edit files to complete your tasks.
