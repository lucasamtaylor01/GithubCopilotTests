# JavaScript/TypeScript Examples - Copilot SDK

This directory contains TypeScript examples demonstrating how to use the GitHub Copilot SDK with JavaScript/Node.js.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## Files

- **index.ts** - Main example showing:
  - Copilot client initialization
  - Sending prompts to Copilot
  - Handling responses and events
  - Basic TypeScript/JavaScript patterns

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up your Copilot SDK environment (authentication required)

## Running Examples

```bash
npm run dev
# or
npx ts-node index.ts
```

## Key Concepts

- **Async/Await**: JavaScript promise-based async patterns
- **Event Handling**: Managing Copilot service responses
- **TypeScript**: Type safety for SDK integration
