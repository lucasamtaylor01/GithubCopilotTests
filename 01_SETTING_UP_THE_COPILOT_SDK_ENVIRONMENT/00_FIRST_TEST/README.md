# First Test - Copilot SDK

This directory contains the first test examples for the Copilot SDK with both Python and JavaScript implementations.

## 🚀 Quick Start

### Python
```bash
cd 00_PYTHON/
pip install -r requirements.txt
python first_agent.py
```

### JavaScript/TypeScript
```bash
cd 01_JAVASCRIPT/
npm install
npm run dev
```

## Contents

- **00_PYTHON/** - Python asyncio-based Copilot SDK example
- **01_JAVASCRIPT/** - TypeScript/JavaScript Copilot SDK example

Both examples demonstrate how to:
- Initialize a Copilot client session
- Send prompts and handle responses
- Manage async/await patterns
- Handle events from the Copilot service
