# Educational Examples - Asyncio

Basic examples to understand asyncio and functools.partial before diving into the Copilot SDK.

## Files

- **asyncio_example.py** - Demonstrates:
  - Creating coroutines with async/await
  - Running async functions with asyncio.run()
  - Event loop basics
  - Handling multiple async operations

- **partial_example.py** - Demonstrates:
  - Creating partial functions with functools.partial()
  - Binding arguments to functions
  - Use cases for partial functions in async contexts
