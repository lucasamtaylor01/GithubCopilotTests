# Setting Up the Copilot SDK Environment

This directory contains practical examples and tests for setting up and using the GitHub Copilot SDK in different programming languages.

## 🚀 Quick Start

### Python
```bash
cd 00_FIRST_TEST/00_PYTHON/
pip install -r requirements.txt
python first_agent.py
```

### JavaScript/TypeScript
```bash
cd 00_FIRST_TEST/01_JAVASCRIPT/
npm install
npm run dev
```

## Structure

- **00_FIRST_TEST/** - Initial tests with Copilot SDK integration
  - **00_PYTHON/** - Python examples using asyncio and the Copilot SDK
  - **01_JAVASCRIPT/** - TypeScript/JavaScript examples with the Copilot SDK
